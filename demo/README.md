# 動画用のデモ音声

YouTube の動画で、端末に話しかけるところを流すための音声。
このマシンのスピーカーから鳴らして実機に聞かせる。

## ウェイクワードと用件は分けてある

端末は「ずんだもん」に気づくと**効果音**（`wake.mp3`, 約 1.0 秒）を鳴らす。
**その間もマイクは録り続けている** —
[MainActivity.kt](../device/android/app/src/main/kotlin/jp/local/aichat/device/MainActivity.kt)
の `Event.Wake` は鳴らすだけで、聞き取りを止めない。
続けて喋ると**用件の頭が効果音と重なる**ので、鳴り終わってから用件を鳴らす。

```sh
afplay demo/00-wake.wav        # 呼ぶ → 端末が効果音を鳴らす
afplay demo/05-timer-10s.wav   # 鳴り終わってから用件
```

間に無音（既定 1.4 秒）を挟んだ **1 本もの**もある。続けて鳴らすだけでよく、
撮影中に手を動かさずに済む。

```sh
afplay demo/05-timer-10s-full.wav
```

| | |
|---|---|
| `00-wake.wav` | 「ずんだもん」だけ |
| `NN-*.wav` | **用件だけ**（ウェイクワードは入っていない） |
| `NN-*-full.wav` | ウェイクワード＋無音＋用件 |

## ボタンで鳴らす（リモコン）

撮影中に `afplay` を叩くのは手間なので、ボタンを並べた頁を用意した。

```sh
./demo/serve.sh          # 起動してブラウザで開く
PORT=9000 ./demo/serve.sh
```

- 上の大きいボタンが**呼びかけ**。押すと端末が効果音を鳴らす
- 効果音が鳴り終わってから、下の**用件**のボタンを押す
- 「呼びかけ込みで鳴らす」に印を付けると、ボタン 1 つで `-full` を鳴らす
- <kbd>Space</kbd> 呼びかけ ／ <kbd>1</kbd>–<kbd>9</kbd> 上から順に ／ <kbd>Esc</kbd> 止める
- 前の音は必ず止めてから鳴る。**重ねると端末が聞き取れない**

ボタンの並びは [commands.json](commands.json) から作る。これは `gen.sh` が
台本から吐くので、**台詞を直せば頁も直る**（頁の側に書き写さない）。

**`file://` で開いても動かない。** `commands.json` の fetch がブラウザに
止められる。`serve.sh` は静的サーバー越しに出している。

## 会話を終える言葉

追い質問の窓（既定 8 秒）が開いている間に言う。呼びかけは要らないので、
この 4 つには `-full` を作っていない。頁の上では**枠が破線**になっている。

**終わりを決めるのは AI。** 文字列一致で黙って閉じるのではなく、
AI が `end_chat` 道具を呼んで終わりを伝える。**別れの挨拶を言ってから**
閉じるので、鳴らすと返事が返ってくる（[session.ts](../device/server/src/ws/session.ts)
の「終わりを決めるのは AI」）。

そのため**この 4 つも AI を呼ぶ**（`live` なら課金される）。

## 作り直す

家の VOICEVOX を呼んで、このフォルダに吐く。

```sh
./demo/gen.sh                          # 春日部つむぎ（既定）
SPK=2 ./demo/gen.sh                    # 別の話者で
GAP=2.0 ./demo/gen.sh                  # 効果音を待つ間を延ばす
HOST=http://<VOICEVOX の IP>:50021 ./demo/gen.sh
```

24kHz / 16bit / モノラルの WAV。繋ぎは [join.py](join.py)（**sox は使わない** —
入っていない機械がある。`wave` は標準添付）。

**話者にずんだもん（3）は使わない。** ウェイクワードが「ずんだもん」なので、
話しかける側と端末の声が同じキャラだと、見ている人がどちらの声か取り違える。

## 中身

台本は [session.ts](../device/server/src/ws/session.ts) の道具の並びから採った。

| ファイル | 狙い |
|---|---|
| 00-wake | ウェイクワード。割り込みにも使う（読み上げ中に鳴らす） |
| 02-weather | 一息で言い切る（3 秒待たない） |
| 03-weather-today | 検索 |
| 04-clock | 今何時。道具ではなく指示文の「いま」で答える |
| 05〜09 timer-* | かける・残り・重複・取り消し・名前つき |
| 10〜14 vol-* | 大きく・小さく・最大・半分・いまいくつ |
| 15 house-power | 家の消費電力 |
| 16 ice-water | 製氷機の水 |
| 17〜19 pc-* | PC の電源（状態・入・切） |
| 20〜21 hello / selfintro | 導入、雑談 |
| 22〜25 aizuchi-* | 相槌。**呼びかけは要らない**（追い質問の窓で言う） |
| 26〜29 tsunagi-* | 話をつなぐ言葉。**呼びかけは要らない** |
| 30〜33 end-* | 会話を終える言葉。**呼びかけは要らない** |
| 34-train | 検索。運行情報 |
| 35-ice-can | 遠回しな聞き方（道具は水の有無しか分からない） |
| 36, 38 pasta-yude / shoyu | 雑談。道具を使わず知識で答える。**答えが定まる問いにする**（開いた問いは薄い返事になった） |

## git に入れていない

wav は追跡しない（[.gitignore](../.gitignore)）。**素材の扱いを立ち絵・効果音と
揃えた。** 台本は `gen.sh` にあるので、走らせれば手元で作り直せる。
