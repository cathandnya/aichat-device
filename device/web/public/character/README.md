# 立ち絵

ずんだもんの画像を**ここに置く**。`.png` は git に入れていない
（`.gitignore` 済み）ので、clone しただけの状態では空になる。

**画像が無くても画面は壊れない。** 立ち絵が出ないだけで、
文字も声もそのまま動く（`src/main.ts` が読み込みを確かめてから出す）。

## 何を置くか — **4枚1組**

| ファイル | 中身 |
|---|---|
| `normal.png` | 土台。**口が描かれていない**（目・頬はある） |
| `mouse_0.png` | 閉じた口（〜）。**既定** |
| `mouse_1.png` | 半開き |
| `mouse_2.png` | 大きく開く |

- **4枚とも同じキャンバスの大きさにすること**（いまは 1082×1650）。
  重ねて位置を合わせるので、1枚でも大きさが違うと口がずれる
- 口の3枚は**口以外が透明**であること
- **土台に口を描かない。** 描くと、開いた口を重ねたときに二重になる

口は常に1枚重なっている。喋っている間だけ `mouse_0 → 1 → 2 → 1 → 0` と
切り替わる（`src/character/mouth.ts`）。

## 感情で差し替える予定

`normal.png` は「ふつう」の表情。感情に応じてここを差し替える予定がある
（`docs/08-emotion.md`）。口の3枚は表情によらず共通で使えるよう、
**土台と口を分けたまま**にしておく。

## リポジトリに入れるとき

**入れる前に配布元の利用規約を確かめること。** 公開リポジトリなので、
画像を commit すると再配布にあたる。規約が許していることを確認できたら
`.gitignore` の `device/web/public/character/*.png` を外す。
