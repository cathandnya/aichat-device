# 01. 要件と前提

## ゴール

家のテーブルに置いて、話しかけると Claude / Gemini が答えるデバイス。
利用者は家族。

端末は **Echo Spot 初代（2017）に LineageOS を入れたもの**
（[06](06-device-implementation.md)、手順は [09](09-echo-spot-jailbreak.md)）。
**判断も推論もローカルサーバーに集める**ので、端末は音を送って
音と絵を出すだけでよい。

## 前提

| 項目 | 決めごと | 端末側への影響 |
|---|---|---|
| 回答 | Claude / Gemini の SSE を共通形式（`delta` / `sources` / `done` / `error`）に正規化 | 逐次表示と先読み読み上げが素直に書ける |
| 音声認識 | 音声のバイト列を受け `{"text":"..."}` を返す。16kHz mono WAV 想定・上限 1,000,000 バイト（約31秒） | 端末は **16kHz mono 16bit** を 80ms ずつ流す。録音は 20 秒で打ち切る |
| 鍵 | **ローカルサーバーだけが持つ。** `.env` か OS の鍵束から読む | 端末には渡らない |
| 認証 | **持たない。** 守っているのは待ち受けアドレス（`HOST=127.0.0.1`）。`/admin` は `ADMIN_PASSWORD` を入れたときだけ鍵がかかる（既定は空） | LAN に開くなら認証を足す必要がある |
| 設定 | モデル・システムプロンプト・回答の長さ・音声認識モデルは `/admin` で決める | **端末に設定画面は要らない** |
| 会話履歴 | **サーバーが持つ**（[07](07-chat-design.md)） | 端末は `chatId` を持つだけ |
| 画像 | Claude 形式の `image` ブロックを受け付ける | カメラを足しても上流の扱いは変わらない |
| 端末内モデル | **持たない** | provider は claude / gemini の二択 |

## 機能要件

### 必須

1. 話しかけると答える。開始は**ウェイクワード**（既定「ずんだもん」）。
   **画面にボタンは置かない**（実機に無いため）
2. **日本語の音声認識**。家族の会話なので日本語精度を最優先
3. **内容は声で聞く。** 実機は 2.5 インチの丸（480×480）で、離れたら
   文字は読めない。**画面は顔と状態を映す**（[06](06-device-implementation.md)）
4. **日本語の読み上げ**。1文できた時点で先に喋り始める
5. 状態を明示（待機 / 聞き取り中 / 考え中 / 回答中 / 追い質問 / エラー）。
   **実機は顔と色で示す**（喋っている間は口が動く）
6. 待機時は時計。常時点灯していて邪魔にならない
7. 電源を入れれば勝手に起動する（キオスク運用）

### 実装済み

- 出典（`sources`）の表示
- 追い質問（回答後しばらくはウェイクワード無しで続けられる。[07](07-chat-design.md)）
- **タイマー**。「3分のタイマーかけて」で数えて、時間が来たら1回だけ知らせる。
  **1台1本だけ**で、動いている最中にもう1本頼まれたら残り時間を伝える。
  意図の理解は Gemini の function calling、時間の管理はサーバー（`src/timers.ts`）

### やらない

- スマートホーム操作・音楽再生などの Alexa 的スキル（チャット専用に絞る）
  - タイマーだけは例外。**アレクサで一番使っていた**ため
- 端末側の設定画面（設定はサーバー側で完結させる）
- 物理ミュートスイッチ。**使えない。** Echo Spot に付いてはいるが
  LineageOS では動かず、MUTE ボタンが電源ボタンを兼ねる（[09](09-echo-spot-jailbreak.md)）

## 非機能要件

| 項目 | 目標 |
|---|---|
| 応答遅延 | 話し終わり → 喋り始め **2 秒以内**（STT 0.5s + 初回トークン 1s + TTS 0.5s の目安） |
| 誤起動 | 1 日数回以下。テレビの音で起きないこと |
| プライバシー | 音声は必要なときだけ**家の外に**出す。ウェイクワード検出は**家の中で完結させる**。<br>判定するのは端末ではなく**家の中のサーバー**なので、**部屋の音が常時 LAN を流れる**。<br>家の外に出ない点は変わらないが、経路の保護が要る（[06](06-device-implementation.md)） |
| コスト | ランニングは API 課金のみ。端末は手持ちの Echo Spot なので 0 円 |
| 運用 | SSH で更新できる。再起動で復旧する。操作はウェイクワードのみ |
| 検証 | **UI と音声の一周を、AI に課金せずに確かめられること**（stub モード） |
| 鍵 | 家に置く箱に長期の課金キーを置く以上、上限付きのキーを使う |
